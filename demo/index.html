sheep.exe.js

The 1995 desktop sheep (Screen Mate Poo, a.k.a. Stray Sheep), running from a TypeScript port of the original Win16 Sheep.exe. Its sprites, sounds and behaviour tables were extracted from the binary.

It walks on page elements the way the original walked on window title bars. Drag it with either mouse button. Double-click it for the settings dialog, Shift+Ctrl+double-click for the debug dialog, and double-right-click to remove it.
